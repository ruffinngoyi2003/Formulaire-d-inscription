# Nom du projet: Formulaire d'inscription
Un formulaire simple en HTML et CSS permettant aux utilisateurs de s'inscrire.
## Technologies utilisées
-HTML
-CSS
## Aperçu
Un formulaire responsive avec des champs classiques: nom, prénom, email, mot de passe.
